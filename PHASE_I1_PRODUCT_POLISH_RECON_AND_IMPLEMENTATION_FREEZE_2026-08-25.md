### 3.1 Navigation / accessibility polish — NEEDS_WORK (high value, small change)

Measured on the rendered product (audit.json `pages.*.structure.nav`, all five pages):

- Nav container is a plain `div.comfymodal-studio-topnav`; **no `<nav>` element, no role, no `aria-current` anywhere** (0 occurrences in `web/`). Active page is conveyed by `.active` class only — invisible to assistive tech.
- Nav items are `<button data-page>` — correct element choice for in-app view switching (no URL change exists); keep buttons, do NOT convert to links.
- Keyboard traversal verified: Tab order = nav buttons → page content, in DOM order; Shift+Tab reverses; nav button `:focus-visible` = solid 2px outline (GOOD).
- Shell dialog (`modal-testing.js`): `role="dialog"`, `aria-modal="true"`, `aria-labelledby` ✓; Escape closes via layer registry ✓; focus moves into modal on open ✓; focus restored to trigger on close ✓; background made `inert` + `aria-hidden` ✓ (this provides effective Tab containment).
- **Dead code:** `_trapTab` (`modal-testing.js:15`) is defined and never wired — containment is achieved by `inert`; the helper should be deleted by the lane that owns this file.
- **Generation detail overlay does not move focus in on open** (measured `focusInsideOverlay: false`); Escape closes and restores focus to the originating card ✓. Focus-into-dialog is the gap.
- Duplicate accessible names (measured): "Add to favorites" ×7 (History cards — no record context in label), "Reset section" ×5 (Settings — no section name), recent-run carousel items share one identical label ("Preset A - completed - Click to view" ×4 — no time/id), "Portability: Not analyzed. Opens the portability panel." ×4.
- History generation/experiment cards use `div role="button" tabindex="0"` + keydown — functional and acceptable; native `<button>` preferred but NOT required by this freeze.

**FROZEN:** wrap nav in `<nav aria-label="Studio pages">`; set `aria-current="page"` on the active nav button (remove nothing visual); move focus to the detail overlay's close button (or first control) on open, restoring to the card on close (Escape already restores); add disambiguating context to duplicated labels (favorite star → include record meta; Reset section → include section name; carousel items → include time/id); delete dead `_trapTab`. No ARIA beyond these native-first additions.

### 3.8 URL / deep-link routing — NEEDS_WORK (smallest truthful architecture)

Measured facts: **zero** `pushState`/`replaceState`/`hashchange`/`popstate`/`location.hash` usage in `web/`. Studio is a **modal overlay inside the ComfyUI page** (opened via sidebar "Modal GPU", fallback launcher, or programmatic `open_testing_modal(alias)` with the 7-alias `ALIAS_PAGE_MAP`; `comfymodal.open-section` event opens Settings and scrolls to `[data-section]`). Active page is in-memory only (`studio-shell.js` state); reload always lands on Playground. Persisted today: playground selection/drafts/results/workflow-handoff (LS), History view-state (LS), preview/GPU prefs (LS). Browser Back/Forward: nothing (and Back currently leaves the whole ComfyUI page).

**FROZEN routing contract (hash-based, no router library):**

- **Format:** `#comfymodal=<page>[&focus=<id>]` — e.g. `#comfymodal=history&focus=gen_x`, `#comfymodal=workflows&focus=wf_x`, `#comfymodal=backend&focus=deployment`, `#comfymodal=settings&focus=outputs`. One focus id max; page ∈ the five canonical ids.
- **Parse/serialize owner:** `modal-testing.js` parses on `open_testing_modal()` (and on `hashchange` while open); `studio-shell.js` gains a `setPage(id, {source})` hook that serializes via `history.replaceState` for selection changes and `pushState` on page changes (so Back returns to the previous Studio page while the modal stays open).
- **Invalid/unknown ids:** fail soft — land on the page without the focus selection (never error, never fabricate).
- **Back/Forward:** `hashchange` listener applies page/focus when the modal is open; when closed, a `#comfymodal=` hash on open honors it (copied URL / reload then reopen works).
- **Reload:** ComfyUI reload closes the modal (host-owned page); on next manual open the hash is honored. This is truthful — Studio has no standalone page to restore.
- **Old-link compatibility:** aliases and `open_testing_modal` unchanged; absent hash = today's behavior exactly.
- **Rejected:** any routing library (five pages, one focus param — a hash parser is ~40 lines); path-based routing (would fight the ComfyUI host); putting drafts/filters/run state in URL (transient state stays out).

### 3.9 Cross-tab state synchronization — freeze the MINIMUM contract

State inventory: SERVER_AUTHORITY = History V2, workflows/presets/models, backend workspace/deploy/credentials, snapshots. DURABLE_BROWSER_PREFERENCE = `comfymodal_gpu`, `comfymodal_preview_*`, `comfymodal_heavy_tracing`, playground selection keys, History view-state. EPHEMERAL_VIEW_STATE = active page, subtabs, filters, drafts. RUN_STATE = per-tab run controller/polling. **UNSAFE_TO_SYNC = RUN_STATE and EPHEMERAL_VIEW_STATE.**

Measured: **zero** sync mechanisms today (no `storage` listeners, no BroadcastChannel). User-visible two-tab bugs: (1) GPU/preview preference changed in Tab A → Tab B serves stale LS-cached values until remount; (2) workspace activate/swap or deploy in A → B's Backend page stale; (3) favorite/note in A → B's History stale; new generations never appear in B without re-render; (4) workflow/preset edits stale in B.

**FROZEN minimum contract:** one `BroadcastChannel("comfymodal-studio")` (no storage-event fallback needed; supported in all evergreen browsers). Message schema `{ kind: "settings" | "workspace" | "history" | "workflows", at: epochMs }`. Receiver behavior: mark the matching store stale and refetch **on next visibility/render** (settings + workspace may refetch immediately — they are small); never merge remote state into local UI state directly; never sync selection, drafts, or run state; never create a second authority for server-owned data. No polling, no revalidation frameworks.
